自己レビュー（コード品質 + ドキュメント整合性チェック）を行います。

## 手順

1. `/simplify` スキルを呼び出して、変更コードの再利用性・品質・効率のレビューと改善を行う
2. ドキュメント検証サブエージェントを呼び出して、変更内容とドキュメント（README、SKILL.mdなど）の整合性を検証する
   - 変更されたコードや機能に対応するドキュメントが最新かどうかを確認する
   - 古くなったドキュメントや不整合があれば修正する
3. Markdownファイルの相対パスリンクを検証する
   - `git diff --name-only HEAD` で変更されたファイルの一覧を取得し、`.md` 拡張子のファイルを抽出する
   - 各Markdownファイルについて、`[text](path)` 形式のリンクを抽出する（コードブロック内は除く）
   - リンクが相対パスの場合（`http://` や `https://` で始まらず、`#` のみで始まらない場合）、フラグメント識別子（`#` 以降）を除去した上で、そのMarkdownファイルの実際の位置から相対パスを解決して、ファイルが存在するか確認する
   - 存在しないファイルを指しているリンクがあれば報告し、正しいパスに修正する
4. 修正があった場合はコミットする
